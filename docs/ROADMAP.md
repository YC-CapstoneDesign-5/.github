## 단계별 구현 로드맵

| 단계 | 구현 내용 | 기능 | 다음 단계 진입 기준 |
| :---: | :--- | :--- | :--- |
| **Phase 0** | 양식 샘플 확보(부서 엑셀·스캔 출석부·4대보험 원본·기관 업로드 규격), 가상 데이터셋 생성 | — | 실제 양식과 같은 구조의 가상 데이터 준비, 기관 규격 확정 |
| **Phase 1** | 행정망 단독 구동 환경, 5개 역할 RBAC, 계정·세션 보안, 감사 로그, 암호화 저장, 참여자 마스터 CRUD | FN-01, NFR-05~10 | 역할별 API 거부 테스트 통과, 날짜별 참여 이력 조회 |
| **Phase 2** | 부서 공통 제출 포털(입력 정규화·양식 변조 차단·버전), 엑셀 취합 보조 경로, 검증 룰 엔진 | FN-09, FN-02, FN-05 | 수작업 취합 정답과 100% 일치, 재업로드 중복 없음 |
| **Phase 3** | 부서장 승인·공문 연계, 전월 대비 변경 감지·계좌 변경 잠금 | FN-10, FN-11 | 승인된 제출본 잠금, 계좌 변경자 지급 확정 차단 |
| **Phase 4** | 모바일 전자출석(PWA), 스캔 출석부 OCR 대조 | FN-12, FN-06 | 3터치 입력·2초 저장, OCR 1장 60초 이내·일치/불일치/미판독 분류 |
| **Phase 5** | 월별 인건비 계산, 중도 입·퇴사 정산, 연차 규칙 | FN-03, FN-14 | 기존 수기 정산 사례와 1원 단위까지 일치 |
| **Phase 6** | 4대보험 다차원 귀속 매칭, 공제 확정, 퇴사자 환급 추적 | FN-04 | 해당 사업 / 타 사업 / 확인 필요 완전 분류 |
| **Phase 7** | 기관별 Export(EX-01~05), 일모아·인사랑 일괄 등록, 확인서·청구서 서명 | FN-07, FN-16, FN-13 | 합계 불일치·필수값 누락 시 출력 차단, 재서명 흐름 동작 |
| **Phase 8** | 현황 대시보드·웹 알림, 제출 독촉·마감 관리 | FN-08, FN-15 | 미처리 드릴다운, 일정대로 자동 독촉 |
| **Phase 9** | 한 달 전체 사이클 E2E, 부하·접근성·호환성·복구 테스트, 시범 운영 | NFR-01~04, 11~18 | NFR 기준 충족, 월 업무 1일 이내 |

## 대표 검증 시나리오

1. **정상 근무 및 중도 입·퇴사자 복합 케이스**: 일할 근무급, 미지급 주휴, 미사용 연차 정산액이 수기 정산 결과와 1원 단위까지 일치하는가? (FN-03, FN-14)
2. **월중 부서 이동 케이스**: 월 중간에 부서를 옮긴 참여자의 근무시간과 부서별 집계가 중복·누락 없이 EX-04에 나오는가? (FN-01, EX-04)
3. **4대보험 동일인 복수 내역 케이스**: 한 사람이 다른 사업에도 부과돼 있을 때 타 사업분이 분리되고 정상 복수 행은 보존되는가? (FN-04)
4. **퇴사자의 과거 환급금 케이스**: 이미 퇴사한 참여자의 과거 귀속 환급이 미환급 현황에 올바르게 잡히는가? (FN-04)
5. **수식 미반영 및 재업로드 케이스**: 수식이 깨진 엑셀의 오류 위치를 지목하고, 같은 파일을 다시 올려도 중복 반영하지 않는가? (FN-02, NFR-12)
6. **양식 변조·입력 형식 케이스**: 열 구조를 바꾼 파일은 거부되고, `260101`·`0101` 같은 날짜가 표준 형식으로 정규화되는가? (FN-09)
7. **승인·반려·잠금 케이스**: 반려 시 사유 없이 저장되지 않고, 승인된 제출본은 직접 수정이 막히며 재제출로만 새 버전이 생기는가? (FN-10)
8. **계좌 변경 케이스**: 전월과 계좌가 다른 참여자가 표시되고, 관리자 확인 전에는 지급 확정이 차단되는가? (FN-11)
9. **전자출석 조퇴 케이스**: 조퇴가 시간으로 저장되면서 근무일수는 1일로 집계되고, 마감 후 수정은 사유 없이 안 되는가? (FN-12)
10. **흐린 스캔 출석부 케이스**: 기울어지거나 흐린 스캔본에서 미판독 항목이 자동 확정되지 않고 원본 위치와 함께 수동 보정 대상으로 나오는가? (FN-06)
11. **금액 변경 후 재서명 케이스**: 서명 후 산출 금액이 바뀌면 이전 서명본이 무효 처리되고 새 버전 재서명이 요청되는가? (FN-13)
12. **Export 차단 케이스**: 개인별 합계와 총괄표 합계가 다르거나 필수 코드가 빠지면 다운로드가 막히는가? (FN-07, NFR-11)
13. **비인가 접근 및 완료 상태 변조 차단**: 다른 부서 담당자가 URL로 접근하면 403이고, 파일을 생성했다고 지급·신고 완료로 바뀌지 않는가? (NFR-09, FN-08)
14. **마감 독촉 케이스**: 마감일에 미제출·미승인·반려 부서에 웹 알림이 반복 발송되고, 대리 제출자가 대신 제출할 수 있는가? (FN-15)
15. **내부망 단독 구동 케이스**: 외부 네트워크를 차단해도 폰트·스크립트·알림·OCR이 모두 동작하는가? (NFR-05, NFR-08)

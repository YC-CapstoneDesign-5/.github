# 행정 구조대
> **부서별 공공일자리 참여자·출석·급여·4대보험 통합 및 교차 검증·서식 생성 자동화 플랫폼**

---

## Project Overview
지자체 및 공공기관의 공공일자리 사업은 매월 수백 명의 참여자 관리, 복잡한 출석부 대조, 법정 4대보험 공제 계산, 그리고 상이한 상급기관 제출 서식 작성으로 인해 막대한 수작업 행정 비용이 발생합니다.

본 프로젝트는 **흩어진 행정 데이터를 하나로 통합**하고, 룰 기반 검증 엔진을 통해 **오차 없는 교차 검증**을 수행하며, OWPML(HWPX)·OOXML(XLSX) 바이너리 제어를 통해 **기관별 맞춤 서식을 무인 자동 생성**하는 차세대 행정업무 지원 플랫폼입니다.

## Key Problems & Solutions

| 기존 행정 업무의 한계 (Pain Point) | GovWork-Flow의 해결 방안 (Solution) |
| :--- | :--- |
| **기관·부서별 서식 불일치**<br>제출처마다 HWP, HWPX, XLSX 양식이 달라 일일이 복사·붙여넣기 반복 | **XML 기반 템플릿 인젝션 엔진**<br>서버 내 저장된 기관별 서식 템플릿의 XML 트리에 데이터를 직접 주입하여 스타일 깨짐 없는 자동 문서 생성 |
| **수작업 대조로 인한 계산 오류**<br>출석시간-지급액 불일치, 연령별 4대보험 적용 제외자 누락 등 빈번한 행정사고 | **3단계 교차 검증 룰 엔진 (Deterministic Engine)**<br>출결-급여 실시간 대조, 연령·소득별 법정 요율 자동 검증 및 원 단위 절사 검증, 부정수급 이상치 자동 플래깅 |
| **사방에 분산된 행정 정보 및 지침**<br>매년 개정되는 지침서(PDF), 지자체 고시공고, 4대보험 규정을 찾기 위해 반복 검색 | **정보 수집 파이프라인 & 지침 RAG 어시스턴트**<br>관련 사이트 자동 크롤링 및 PostgreSQL `pgvector` 기반 하이브리드 검색으로 법정 근거 조항(페이지) 즉시 제공 |

## Key Features

1. **통합 워크스페이스 & 이종 엑셀 파싱**
   - 부서별로 제각각인 출석부/급여대장 엑셀 헤더를 표준 스키마로 자동 정규화
   - 누락 데이터, 중복 참여자, 포맷 오류 실시간 전처리

2. **출석 · 급여 · 4대보험 자동 교차 검증 (Cross-Validation)**
   - 인정 근로시간 기반 기본급 및 주휴수당 자동 산출 대조
   - 만 60세(국민연금), 만 65세(실업급여) 등 연령별 법정 공제 제외 기준 자동 적용
   - 오차 항목에 대한 직관적인 Diff UI 및 수정 가이드 제공

3. **XML 기반 기관 맞춤형 문서 생성 (Doc Automation)**
   - OWPML 표준 기반 `HWPX` 본문 XML(`section0.xml`) 파싱 및 동적 테이블 행 증설
   - 원본 결재란과 셀 스타일, 여백을 100% 보존하는 `XLSX` 템플릿 주입

4. **행정 규정 RAG & 고시 정보 통합 피드**
   - 두꺼운 사업 지침서 속 모호한 예외 규정을 질의하면 원문 조항과 함께 명확한 가이드 제시
   - 분산된 공공일자리 공고 및 주요 개정 사항을 단일 대시보드에 집약
